# Ubuntu Server Settings

```bash
curl -fsSL https://raw.githubusercontent.com/takeedev/ubuntu-server-settings/refs/heads/main/install.sh | /usr/bin/env bash
```

Enable Firewall

```bash
curl -fsSL https://raw.githubusercontent.com/takeedev/ubuntu-server-settings/refs/heads/main/install.sh | /usr/bin/env bash -s -- --enable-ufw
```

## Programe

- Docker Engine
- Docker CLI
- containerd
- Docker Buildx plugin
- Docker Compose plugin
- UFW
